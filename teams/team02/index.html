Data Speaks: Student Dropout Prediction and Academic Success Analysis

An educational data mining project exploring student outcomes through classification, clustering, and dimensionality reduction.

Problem statement

Student dropout and academic success are important educational outcomes. This project asks how demographic, academic, and enrollment-related data can be used to examine and classify students as Dropout, Enrolled, or Graduate.

The goal is to compare classification approaches and use clustering and dimensionality reduction to describe patterns in the dataset. These analyses identify associations in the available data; they do not establish why an individual student succeeds or leaves.

Dataset

The Predict Students' Dropout and Academic Success dataset contains 4,424 student records and 37 columns: 36 input features and the Target outcome. The target has three classes: Dropout, Enrolled, and Graduate. Features include demographic, academic, enrollment, and semester-performance information.

Project objectives

  • Compare classification models for the three student outcome classes.
  • Explore student profiles using K-Means clustering on selected academic and enrollment features.
  • Use PCA to summarize and visualize structure in the selected feature space.

Methodology

Data quality checks found no missing values or duplicate records. For classification, categorical variables were one-hot encoded and numerical variables standardized within a preprocessing pipeline fitted on the training data. Four classifiers were evaluated on a train-test split.

K-Means and PCA used 11 selected academic and enrollment features after standardization. The elbow method supported choosing four clusters; PCA retained five components for a compact representation. Detailed model results and figures are on the Results page.

Significance and limitations

Classification, clustering, and PCA offer complementary predictive and descriptive views of student outcomes. Results describe patterns in this dataset only: they do not show causal effects, guarantee outcomes for individuals, or establish that the same patterns apply to other student populations.

Tools used

Python, pandas, and scikit-learn for data preparation and analysis; project figures document the classification, clustering, and PCA results.
