Data Speaks: Student Dropout Prediction and Academic Success Analysis

An educational data mining project exploring student outcomes through classification, clustering, and dimensionality reduction.

Problem statement

Student dropout and academic success are important educational outcomes. This project asks how demographic, academic, and enrollment-related data can be used to examine and classify students as Dropout, Enrolled, or Graduate.

The goal is to compare classification approaches and use clustering and dimensionality reduction to describe patterns in the dataset. These analyses identify associations in the available data; they do not establish why an individual student succeeds or leaves.

Dataset

The Predict Students' Dropout and Academic Success dataset contains 4,424 student records and 37 columns: 36 input features and the Target outcome. The target has three classes: Dropout, Enrolled, and Graduate. Input features cover demographic, academic, enrollment, and semester-performance information.

The classification pipeline uses 30 of the available input features (18 categorical and 12 numerical). K-Means and PCA instead use a separately selected set of 11 academic and enrollment features.

Project objectives

  • Compare classification models for the three student outcome classes.
  • Explore student profiles using K-Means clustering on selected academic and enrollment features.
  • Use PCA to summarize and visualize structure in the selected feature space.

Data-quality checks

Before analysis, the workflow checked the record and column structure, data types, missing values, and duplicate records. The project materials do not publish numeric check totals, so no missing-value or duplicate counts are inferred here.

Preprocessing and methodology

For classification, categorical inputs were one-hot encoded and numerical inputs standardized in a preprocessing pipeline fitted on the training data. Four classifiers were compared using a train-test evaluation.

For the unsupervised analyses, 11 selected academic and enrollment features were standardized. The elbow method supported K-Means with four clusters; the target was not used to form those clusters. PCA summarized the same selected feature space using five components. Detailed model results and figures are on the Results page.

Significance and limitations

Classification, clustering, and PCA offer complementary predictive and descriptive views of student outcomes. The findings describe patterns and associations in this dataset; they do not establish causes, guarantee outcomes for individuals, or show that the same patterns apply to other student populations.

Tools used

Python, pandas, and scikit-learn were used for data preparation, modeling, and evaluation. The supplied project figures document the classification, clustering, and PCA results.
