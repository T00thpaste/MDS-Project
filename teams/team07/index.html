Smartphone Based Human Activity Recognition and User Identification Using Machine Learning

One or two sentences that tell a visitor what this project is about and why it matters.

Problem statement

To investigate whether smartphone accelerometer and gyroscope sensor data can accurately identify a user's physical activity and distinguish individual users based on their unique movement patterns. The goal is to classify six activities and identify participants using machine learning, while exploring the personal information that can be inferred from smartphone sensor data.

Dataset

The project uses the processed HAR Using Smartphones dataset from the UCI Machine Learning Repository. It contains measurements from 30 volunteers performing six activities: walking, walking upstairs, walking downstairs, sitting, standing, and lying down. In the source dataset, a waist-mounted smartphone recorded accelerometer and gyroscope signals; the processed data represent these signals through engineered time and frequency features. The notebook loads 10,299 observations and 563 columns: 561 numerical features, a participant identifier (subject), and an activity label (Activity). These features support both activity classification and participant identification. The analysis uses the supplied processed features rather than raw sensor time series

Approach

  • Data Cleaning and EDA: Loaded the activity dataset, checked for missing values, duplicates, and class imbalance, and analyzed sensor features to understand differences between activities.
  • Feature Processing and Visualization: Standardized sensor features, applied PCA for dimensionality reduction, and used t-SNE to visualize activity patterns and participant-specific movement signatures.
  • Model Training and Evaluation: Trained LightGBM classifiers to predict physical activities and identify participants, evaluating performance using a train-test split and accuracy scores.

Tools used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, LightGBM.
